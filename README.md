## Featured work

### [Leo — Adaptive Multi-Agent AI Tutor](https://github.com/MdAsif-Hossain/Multi-Agent-AI-Tutor)

A complete learning workflow powered by four collaborating AI specialists that plan, teach, quiz, evaluate, and re-teach.

`Python` `CrewAI` `Pydantic` `SQLite` `Streamlit` `Gemini` `GitHub Actions`

- Uses validated Pydantic contracts for reliable handoffs between agents
- Combines LLM decisions with deterministic grading and bounded remediation loops
- Preserves learner history in SQLite for personalized future sessions
- Includes an API-key-free preview, automated tests, CI, and a recorded product demo

### [BD Knowledge Agent](https://github.com/MdAsif-Hossain/BD-Knowledge-Agent)

A multi-tool assistant that routes Bangladesh-related questions to structured databases or live web search.

`Python` `LangChain` `FastAPI` `SQLite` `Gemini` `Docker`

- Connects **86,490 records** across three typed SQLite databases
- Protects data with read-only connections and `SELECT`-only query validation
- Provides automatic web-search fallback when the local data cannot answer safely
- Includes a custom web interface, CLI, tests, CI, and Docker support

### [Fine-Tuning BERT for Extractive Question Answering](https://github.com/MdAsif-Hossain/Fine-Tuning-Transformers-for-Question-Answering)

An end-to-end, reproducible question-answering pipeline built with BERT and SQuAD v1.1.

`PyTorch` `Transformers` `Datasets` `SQuAD` `Google Colab`

- Implements character-to-token answer alignment and overlapping windows for long contexts
- Decodes valid answer spans across windows and evaluates with official Exact Match and F1 metrics
- Separates smoke-test results from full-data experiments for honest reporting
- Documents training, inference, qualitative error analysis, and model export in one notebook
